Integration Reference Code

Client applications can perform authentication callbacks with just a few lines of Python using standard JWT validation:

import jwt

# Verify the token returned on redirect callback
try:
    payload = jwt.decode(
        token, 
        JWT_SECRET_KEY, 
        algorithms=["HS256"], 
        audience=CLIENT_ID
    )
    user_email = payload.get("email")
    user_name = payload.get("name")
except jwt.InvalidTokenError:
    print("Signature verification failed!")
